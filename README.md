# DigesterCheck

Independent anaerobic digester condition assessment website for Canada.

## Positioning
**Know before you clean.** DigesterCheck does not perform cleanouts. It reviews available information and operating indicators to help owners decide whether further investigation or cleanout planning should be considered.

## Site
Static HTML/CSS/JS designed for simple GitHub Pages or custom-domain deployment.
